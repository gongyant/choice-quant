# P5 字段定义(财务与风险)

数据来源:东方财富 业绩报表(yjbb)与资产负债表(zcfz),按报告期抓取,存于 p4_top5_quant\fin_raw(只读)。
**可用时点规则**:报告在 NOTICE_DATE(公告日)之后的**第一个交易日**才可用;信号日 T 只用 NOTICE_DATE < T 的报告(10-21 实测最大公告日 2026-10-20,未污染)。

| 字段 | 定义 | 注意 |
|---|---|---|
| roe_raw_ytd_pct | WEIGHTAVG_ROE,报告期累计(半年报=上半年 6 个月)加权平均 ROE,原始值 | 半年报约为全年的一半,**不可**与年报 ROE 直接比较 |
| roe_annualized_pct | roe_raw × 4 / q(q=1,2,3,4 对应 Q1/H1/9M/FY) | 简单年化,假设各季均匀;季节性强的行业误差大 |
| eps_ytd | BASIC_EPS 报告期累计 | |
| eps_annualized | eps_ytd × 4 / q | P4 的 E2 特征与 P4 页面的 pe_ann 用此口径 |
| eps_ttm | 最新累计 + 上年年报 − 上年同期累计(年报期直接取年报) | 任一缺失→"未取得";股本变动未调整 |
| pe_ttm | 收盘价 / eps_ttm;eps_ttm ≤ 0 →"未取得(亏损)" | P5 五股对比用此口径。全池中位相对差(年化 vs TTM)21.6%,35% 股票差 >20%,152 只符号不一致 |
| pe_annualized | 收盘价 / eps_annualized | 仅作对照 |
| pb | 收盘价 / BPS(最新报告期每股净资产) | 未扣除少数股东;BPS ≤ 0 →"未取得" |
| netprofit_ytd / ttm | PARENT_NETPROFIT 归母净利润;TTM 同 eps_ttm 拼接 | 单位 亿元 |
| ocf_per_share_ytd / ttm | MGJYXJJE 每股经营现金流(累计 / TTM 拼接) | **券商、保险、银行**经营现金流含客户资金与保费,不能当作"盈利质量",五股中 601066、601318 适用此警示 |
| ocf_to_eps_ytd | 每股经营现金流 / 每股收益 | >1 表示现金流覆盖利润(一般企业);金融业不适用 |
| rev_yoy_pct / np_yoy_pct | YSTZ / SJLTZ 同比 | 基数小时失真 |
| debt_ratio_pct | zcfz.DEBT_ASSET_RATIO | |
| 缺失值 | **视为不可得**:显示"未取得",不填 0、不填行业均值 | E2 模型特征中缺失→横截面排名 0(中位,即"中性未知"),这是模型训练口径,已在审计中披露;展示与买入标准中一律按"未取得"处理 |

风险字段:vol20 = 20 日复权日收益标准差;volp = 合格池内 vol20 分位;dd60 = 收盘相对 60 日最高的回撤;r5/r20 = 5/20 日复权收益;beta60 = 60 日对合格池等权收益的 β;
hist_5d/20d_p05 = 近约 2 年滚动 5/20 日收益的 5% 分位(历史经验,不是预测)。

10-22 一日更新:新浪行情 15:35(UTC+8)收盘快照;复权日收益 = 收盘 / 昨收(交易所除权后)−1;合格池成员与 amt20 沿用 10-21 值(近似,已披露);
B3 的 E2 半边使用 10-21 的最新预测分(10-22 特征未重建),低波半边与约束使用 10-22 数据。
