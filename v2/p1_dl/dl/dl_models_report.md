- MAE 不适用:只做排序任务,没有收益回归头。

## 5. 训练与算力
- B1 MLP:CPU(torch 2.14.1+cpu),156 个模型共 695 s,整个 walk-forward 733 s。
- B2 GRU:CPU 估算每个模型 40–100 s(已做 4 倍降采样),全量 3 种子预计 >4 小时,超出预设的 2.5 小时线。随后在独立 venv `.venv_cuda`(torch 2.11.0+cu128)里装好 CUDA 版,验证 `torch.cuda.is_available()=True`(RTX 5070 Ti,sm_120),GRU 前后向通过;全量数据每 epoch 约 2 s。**因此没有降采样,没有减种子**:52 次再训练 × 3 种子 = 156 个模型,训练 1111 s,平均每个 7.1 s,整个 walk-forward 1158 s。原 `.venv`(CPU)未改动,测试仍在其上运行。
- 另有一次 CPU 降采样的保险运行(种子 42、4 倍降采样),跑到第 23 次再训练就被停掉,产物已删除,不用于任何结果。
- GRU 早停最佳轮数平均 2.6(1–8),验证 MSE(按训练标准差归一化)约 0.992–0.994,与 MLP 的 0.994 同量级,说明信号很弱。
- GPU 结果设置了 cuDNN deterministic,但与 CPU 不保证逐位一致。种子复现测试在 CPU 上做。

## 6. 诚实结论
1. **GRU 没有优于 HGB / LGBM / MLP。** 三种子均值的年化 5.4%,低于 HGB 7.9%、MLP 8.6%;RankIC 0.0705 也略低。配对差全部不显著。
2. **GRU 的种子波动比模型之间的差异还大**:年化从 -2.8% 到 +4.5%,RankIC 从 0.0635 到 0.0734。三种子最新日分数的 Spearman 相关只有 0.68–0.74;GRU 与 MLP 的最新日分数相关仅 0.30。
3. **相对同制度等权的净超额不显著**(t=0.52,bootstrap 含零)。零成本下毛超额 t=1.64,也低于 HGB 的 2.10。
4. **最大回撤更深**(-44%,HGB/MLP 约 -35%),换手更高(替换比例 0.726),成本敏感性更差。
5. 60 日序列信息并没有在这个样本上带来可见增益。可能的原因(未验证):样本只有 1498 只、信号本身很弱、没有调参。不能因此断言序列模型永远无效。
6. **最新日(2026-10-16)GRU 模型**的验证损失约 1.22(大于 1),最佳轮数为第 1 轮。验证窗口(2026-06 至 09)的标签方差高于训练期,所以这个分数的可靠性需要谨慎看待。

## 7. 局限
- 2025–2026 已被多次用于模型比较,不是盲测集;真正的前瞻验证只能从 2026-10-19 之后的新增行情开始。
- 抽样偏差:样本含 13.9% 退市股(总体约 3.6%),结果只代表该样本,不代表全市场。
- 没有历史 ST 序列,涨跌停只能近似;退市后持仓按 P0 的保守处理;920196、600317 成交量单位无法核实。
- 训练使用 CPU/GPU 两套环境(MLP 用 CPU,GRU 用 GPU)。
- 只比较了预注册的单一配置,未做超参搜索,也未做因子消融。
- 行业分类等仅为当前分类,不是历史时点分类。

### B3 诚实结论
1. **Transformer 没有优于 HGB / LGBM / MLP。** 年化 5.5%,低于 HGB 7.9% 和 MLP 8.6%,与 GRU(5.4%)相当;配对差全部不显著(t 绝对值 ≤ 0.35)。
2. **相对同制度等权的净超额不显著**(t=0.46,bootstrap 区间含零);零成本下毛超额 t=1.71,也低于 HGB 的 2.10 与 MLP 的 2.27。
3. **RankIC 是各模型里最高的(0.0776),IC 0.0770 也高于 MLP 的 0.0564**,但与 MLP、HGB 的差异都不显著(t≈0.04–0.45),而且换成 Top50 扣费收益后没有体现为更高的收益。
4. **最大回撤(-37.1%)比 GRU(-44.0%)浅**,与 HGB/MLP(约 -35%)接近;换手与 HGB 相当。
5. 因为只有单种子,这些数字的随机性无法评估。GRU 的三种子结果显示,同一结构不同种子的年化可差 7 个百分点以上。**不能据此说 Transformer 优于或劣于 GRU。**
6. 总体上,11 个量价特征的 MLP 已基本榨干这个样本里的可用信号;60 日序列(GRU/Transformer)没有带来可见增益。可能原因(未验证):样本只有 1498 只、信号弱、未调参。

### B3 额外局限
单种子;GPU 训练(cuDNN deterministic,但与 CPU 不保证逐位一致);Transformer 种子复现测试在 CPU 的小型配置上做;其余局限同第 7 节。
