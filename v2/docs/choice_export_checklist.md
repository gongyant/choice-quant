# Choice 手动导出清单（P2）

原则：只导出你账号授权范围内、许可允许保存的数据；导出文件放到 `D:\choice_quant_starter\v2\data\choice_exports\`（新建），**不要放进 D:\choice**。菜单名称以你本机 Choice 版本为准，下面的名称是任务书/README 中出现的模块名，具体入口我没有在你的界面里核实。

## 1. 板块目录（优先级：高）
- 来源模块：板块监测 / 板块报价。
- 导出：所有行业、概念、地域、风格等板块的“板块代码、板块名称、所属分类(申万/中信/东财/概念…)、成分股数量”。
- 文件名：`choice_board_catalog_YYYYMMDD.xlsx`，导出日期写进文件名。
- 注意：截图里的约650条是板块，不是公司；861226、802096 等是 Choice 板块代码，不是股票代码。

## 2. 板块成分（优先级：高）
- 来源模块：成分报价，或 板块数据浏览器 / 历史成份查询（若你的账号有）。
- 每个板块导出：证券代码、证券名称、纳入日期、剔除日期（若有历史成份功能）。
- 文件名：`choice_board_members_YYYYMMDD.xlsx`（可分多个文件，每个文件一类板块）。
- 没有纳入/剔除日期的，一律只是“当前快照”，不能用于过去的训练。
- “昨日连板”“昨日炸板”“涨停”等动态板块：只能保存为当日快照，不得回填历史。

## 3. 全 A 股日线（优先级：高，用于交叉校验腾讯/新浪数据）
- 来源：数据浏览器/导出 Excel。字段：日期、证券代码、开盘、最高、最低、收盘、成交量、成交额、换手率。
- 先导一个小范围校验：截图里的 9 只股票 2021-01-01 至 2026-10-16，记录复权方式（前复权/不复权）和成交量单位（股/手）。
- 文件名：`choice_daily_9stocks_qfq.csv`。之后用 `choice_import.py` 导入，并与腾讯数据对比收盘价差异。

## 4. 证券基础信息（优先级：中）
- 证券代码、简称、上市日期、退市日期、所属市场（沪/深/北）、ST 状态、总股本/流通股本。
- 用途：校对我用交易所公开清单建立的证券主表，补齐历史退市股。

## 5. 资金与情绪类模块（优先级：低，先核查再用）
- 资金流向、DDE决策、暗盘资金、增仓排名、龙虎榜、市场情绪、板块热图/个股热图：先确认三件事再导出——字段定义文档、是否提供历史日度数据、数据在当天何时发布。
- 这些多为供应商自有算法估算值，不等同于交易所逐笔真实资金流；没有历史数据就不要用于训练，也不能把今天的值倒填过去。
