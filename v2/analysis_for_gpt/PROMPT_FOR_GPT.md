# 请 GPT 帮忙做进一步分析:A 股量化研究(1500 只分层样本,第一阶段)

## 背景
我在做基于东方财富 Choice 的 A 股量化研究。本包是 1500 只分层样本(成功 1498 只,2021-01-04 至 2026-10-16,日线前复权,腾讯/新浪数据)的采集质量报告和初步样本外基线回测。
预测目标:未来 5 个交易日相对收益(减去当日截面均值)。信号 t 日收盘,t+1 收盘买,t+6 收盘卖。滚动训练,训练样本按 5 日标签重叠做了隔离(purge)。Top-50,双边费用 0.3%。

## 文件说明
- backtest_metrics.json:各策略(Ridge/HGB/LGBM/20日动量/5日反转/等权)的年化、夏普、回撤、IC、RankIC、分年表现
- walk_forward_returns.csv:每期各策略的收益序列
- quality_per_stock.csv / quality_summary.json:逐股数据质量与汇总
- sampling_report_1500.json / universe_audit.json:抽样与股票池审计
- latest_research_ranking_DRAFT.csv:草稿排名,仅用于代码检查,不是买入建议
- baseline.py / quality_report.py / sample_universe.py:对应代码
- data_dictionary.md:字段说明

## 已知局限(请在分析中考虑)
1. 1500 只样本不是全市场;在市股票来自当前名单,有幸存者偏差(仅含 2021 年后退市股)
2. 前复权价格是下载时点计算的,不是历史时点复权;行业为最新分类
3. 成本为粗估;未模拟涨跌停排队、100 股整手、容量和冲击成本
4. 买入价假设为 t+1 收盘
5. 我比较了多个模型,显著性需要多重检验折扣

## 请你回答
1. 回测流程里是否有前视偏差或标签泄漏的可能?逐点指出代码位置(baseline.py)。
2. HGB 超额 t=2.65、LGBM 1.81、Ridge 1.01,扣除多重检验后是否还显著?建议用什么检验(如 bootstrap、SPA/Reality Check、Deflated Sharpe)?
3. 20日动量显著为负、模型 RankIC 约 0.07 且每年为正,但 2026 年净收益转负,如何判断信号是否在衰减?
4. 255 只"超涨跌幅限制收益"股票,应如何分类处理(除权、新股首日、复权错误)?
5. 下一步特征(行业中性、流动性、波动率、换手)和更真实的 A 股成本模型(T+1、涨跌停、整手)如何设计?
6. 在扩到 3000 只或全市场前,还需要补哪些验证?
7. 用 quality_per_stock.csv 找出最需要剔除或修正的数据问题。

请不要给出"值得买入"的个股结论,只做方法和证据分析;所有数字请引用文件中的真实值。
