### 2.2 多周期标签的切分推导(不机械套用“回看+horizon”)

- 行 d 的特征只用 ≤d 的数据(60 日回看窗口完全向后),因此**回看窗口不会把信息带到未来,不需要计入 embargo**。泄漏只可能来自标签:行 d 的 h 日标签区间是 close(d+1)→close(d+1+h),在 d+1+h 才实现。
- P1(h=5)几何:验证段末行 hi=i−12,验证 60 日,训练段末 te=vs−10。最晚验证标签到期 hi+1+5=i−6(距信号日 6 个交易日的余量);最晚训练标签到期 te+6=vs−4(早于验证段首行 4 日)。
- 对 Hmax=20,保持**相同余量**:要求 hi+1+20 ≤ i−6 ⇒ hi=i−27;要求 te+1+20 < vs−3 ⇒ 训练/验证间隔 25 日。即两处各加 20−5=15 日,而不是 60+20。`c_tf.split()` 对每个 head 断言这两条到期约束;测试还证明若用 P1 几何训练 20 日头,断言会触发(即存在标签泄漏)。
- 因为 g20 几何本身改变了训练/验证样本(验证段向前移 15 日、训练段少 15+15 日),单独设立 T0G 作为几何对照,使“多周期头”的效果(T2−T0G)不与“purge 变长”混在一起。

### 2.3 损失与正则

- 排序损失:per trading day: sum_{i,j: r_i>r_j} (r_i-r_j)*softplus(-(s_i-s_j)) / sum (r_i-r_j), r = within-day percentile rank of the winsorised label; batches = 6 whole trading days; validation criterion = the same loss on the 60 validation days。
- 持续性正则:loss += 0.5 * mean[(s_d,j - s_d-5,j)^2] / var_batch(s_d) (variance not detached: scale-invariant) over rows whose d-5 row has a valid bar (primary head only); single pre-declared lambda, not tuned(第一次实现中把分母方差 detach 后,模型把分数尺度压到 3.7e-5 来“满足”正则,已改为不 detach;测试校验尺度不变性)。
- 滞后堆叠 LightGBM:the same normalised 60x7 window flattened (420 columns, lag-stacked, incl. mask channel);frozen-LGBM hyper-parameters (num_leaves15, lr.05, min_child200, subsample.8/1, colsample.8, lambda1) with early stopping on the TF validation segment (patience 20, max 400 trees);same P1 geometry / retrain blocks。

### 2.4 度量与检验

- RankIC:P2-A 新口径(信号日可得的候选池,执行日前向收益截面去均值,逐日 Spearman),HAC(4) t 与 5 期 block bootstrap 95% CI。
- 稳定性:相邻信号日(间隔 5 个交易日)在两日都在候选池的股票上分数的 Spearman;Top50 重合:相邻两日 A0 Top50 的交集/50;并区分同一 retrain 块内与跨块的转移。
- 组合:P2-B 的 A0(Top50 等权,P0 模拟器 `simulate_ext`,资本 1000 万),C1 flat 0.30% 双边、C2 显式 OHLCV 成本;换手为单边/期。
- 因子 alpha:净收益减等权 c0 基准,对 P2-A 五因子(SMB、REV5、LVOL、MOM60、ILLIQ)HAC 回归截距;两策略的 alpha 差 = 净收益差序列对因子回归的截距(OLS 线性,测试校验)。
- 配对:同一信号日 A−B 的差序列,HAC t、block bootstrap CI、A>B 日占比;“种子均值”= 先对各种子的逐日序列取均值(等权组合各种子策略),再配对;另给出每个种子的配对结果检验方向一致性。

## 7. 结论(诚实版)

1. P1 Transformer 的 seed 42 结果在 3 个种子的分布之内(RankIC 0.0778–0.0810);信号层种子方差小(std 0.0016),组合层种子方差相对均值很大(C2 净年化 std 2.0%,均值 -1.6%)。跨种子同日分数相关 0.77,Top50 名单在种子之间差异明显,单种子的组合层数字不宜过度解读。
2. 匹配信息集下滞后堆叠 LightGBM 的 RankIC 与 Transformer 无显著差异;没有受控证据支持“Transformer 的序列建模带来额外预测力”。
3. 单因素效果(前 104 信号,种子均值路径):加长 purge(g20):RankIC -0.0039(t -0.75,不显著),稳定性 0.012(不显著),换手 -0.005(不显著),C2 净 -8.9bp/期(不显著),alpha 差 -11.1bp/期(不显著);多周期头:RankIC 0.0010(t 0.28,不显著),稳定性 0.049(显著),换手 -0.059(显著),C2 净 2.7bp/期(不显著),alpha 差 7.1bp/期(不显著);排序损失(单头):RankIC 0.0199(t 2.03,显著),稳定性 0.128(显著),换手 -0.184(显著),C2 净 8.6bp/期(不显著),alpha 差 -22.5bp/期(显著);排序损失(多头):RankIC 0.0285(t 2.97,显著),稳定性 0.109(显著),换手 -0.185(显著),C2 净 18.4bp/期(不显著),alpha 差 -14.4bp/期(不显著);持续性正则:RankIC -0.0511(t -5.86,显著),稳定性 0.271(显著),换手 -0.448(显著),C2 净 15.9bp/期(不显著),alpha 差 17.1bp/期(不显著)。
   读法:排序损失是唯一同时提高 RankIC 和稳定性、降低换手的单因素;多周期头本身主要提高稳定性,不提高 RankIC;持续性正则以大幅牺牲 RankIC 换取换手下降;purge 加长基本无影响。但没有任何单因素在 C2 成本下带来显著的净收益或因子调整 alpha 改善,排序损失的组合还明显增加了 SMB(小盘)暴露(见因子暴露表),所以 RankIC 的提升不能直接解读为经济优势。
   持续性正则对种子很敏感:T4 的 RankIC 各种子在 0.0153–0.0405 之间,跨种子同日分数相关仅 0.25,换手 0.101–0.291。λ=0.5 时模型接近“记住上一期的排序”,预测力不稳定。
5. 多周期头各自的 RankIC 见 §5;多周期 MSE 模型的 20 日头对 5 日实现收益的 RankIC 反而高于 5 日头,排序损失模型四个头几乎相同。这只是信息性观察,没有据此选头,主分数始终是预先声明的 5 日头。
4. 所有 2022-07 以后的数据都已被前序阶段反复使用,本阶段结果一律为探索性。

## 8. 局限与减配说明

- 原因:measured: one 52-block Transformer run takes ~35 min of GPU time (P1: 2059 s); concurrent processes only time-slice the single GPU (about 1.2x total throughput) and Windows commit memory allows 2 workers; 17 full runs would need ~9 h. Declared before any variant result exists.
- T0:43 and 44 run on ALL 52 retrain blocks (seed 42 = frozen P1)。
- 消融:T1,T2,T3,T4,T0G are trained on the FIRST 26 retrain blocks only (signals 0-103, 2022-07 to ~2024-08), seeds 42,43 first and 44 if time allows; all variant-vs-baseline paired tests use exactly these 104 signals (T0 and lag-LGBM are sub-selected to the same signals; the full-207 T0 results are reported separately)。
- 选块:first 26 blocks = contiguous in time (keeps consecutive-signal stability transitions across retrain boundaries) and chosen BEFORE any variant result。
- 实际未完成的(变体, 种子):无。未完成的不进入任何表格。
- 实际执行:T0 三种子 × 52 块、LAGLGBM 三种子 × 52 块全部完成;5 个消融变体 seed 42/43/44 各跑完前 26 块(seed 44 按用户“必要时接着跑完”的意见补跑,17:38–19:14 全部完成;原 seed 42/43 的数字保留在 `results\c_*_s42s43.csv` 并在 §5b 对照)。3 个种子的 t 区间自由度只有 2,仍应以逐种子方向是否一致为主要参考。前 104 信号(2022-07 至 2024-08)整体是下跌市,所有变体的绝对净年化都为负,应看配对差与超额,不看绝对水平。
- 未做:额外种子 45/46;消融变体在后 26 块(2024-08 以后)的结果;多个持续性 λ 的扫描(只有一个预先给定的 λ)。
- 前 104 信号只覆盖约 2 年,配对检验功效有限;3 个种子不足以可靠估计种子方差。
- LGBM 早停在后段经常只保留极少树,其分数离散(大量并列),Top50 选择受并列打破规则影响;固定 200 树的事后敏感性仅 seed 42。
- 候选池、成本模型、因子均沿用 P2-A/P2-B;行业为最新而非时点数据(P2-A 已披露)。
