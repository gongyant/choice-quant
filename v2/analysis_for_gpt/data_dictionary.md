# 数据字典（P1 当前版本）

## 日线 `data/raw_parquet/<code>.parquet` 与面板 `data/panel_1500.parquet`
| 字段 | 含义 | 备注 |
|---|---|---|
| code | 6位证券代码(字符串) | 板块代码不会出现在这里 |
| date | 交易日 | |
| open/high/low/close | 前复权价格 | 复权因子在下载当天由数据源计算，非逐日点时数据 |
| volume_raw | 数据源原始成交量 | 单位随股票不同：有的是股，有的是手，个别为股数的100倍，见质量报告 |
| volume_shares | 校正后成交量(股) | 用成交额/收盘价逐年反推单位；无法验证则为空 |
| amount | 成交额(元) | |
| turnover | 换手率(小数，0.0177=1.77%) | |
| outstanding_share | 流通股本 | 仅新浪(北交所)提供 |
| source | tencent.stock_zh_a_hist_tx 或 sina.stock_zh_a_daily | |
| adjust | qfq | |
| fetched_at | 下载时间 | |

## 证券主表 `data/universe_master.csv`
证券代码、名称、交易所、板块(沪主板/科创板/深主板/深主板原中小板/创业板/北交所/B股)、上市日期、退市日期、状态、巨潮行业(最新生效分类，非历史时点)、最近交易日成交额(仅用于抽样分层)。

## Choice 模块（尚未核实的部分已标明）
| 模块 | 通常含义 | 历史数据可得性 |
|---|---|---|
| 板块监测/板块报价 | 板块行情与目录 | 需在 Choice 内确认，当前无导出数据 |
| 成分报价 | 板块成分股与行情 | 需确认是否有历史成份 |
| 板块热图/个股热图 | 涨跌可视化 | 通常是当时画面，未核实有历史 |
| 市场情绪 | 涨跌分布等 | 未核实 |
| 增仓排名、资金流向、DDE决策、暗盘资金 | 供应商算法指标 | 未核实；不等于真实资金流 |
| 龙虎榜 | 交易所公开披露的异常交易信息 | 公开信息，发布时间需与可交易时间对齐 |
