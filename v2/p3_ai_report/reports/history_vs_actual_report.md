# 历史预测 vs 真实涨跌(P3 第二批)

> 研究复盘,不是买入推荐。**2025–2026 年不是盲测**:这段数据在 P1/P2 已被反复查看,只能算探索性复核;2022-07~2024-12 也属模型的走步样本外(walk-forward OOS),但规则设计时研究者已经见过 P1/P2 的汇总结果。所有收益为事后实现值,分数不是概率。

## 1. 先说结论

- 207 个历史信号日(2022-07-01 ~ 2026-09-28,约每周一期)里,综合分数越高的组,之后 5 日和 20 日的**平均**相对表现越好,但差距很小:最高组 5 日平均比池子多 +0.35%,最低组少 0.92%。
- 按 v1 规则每期选出的 Top5,全期平均每期 5 日收益 +0.24%,同期全池平均 +0.19%;跑赢全池的期数占比(命中率)只有 47%。**累计(成本前)+14.0%,同期全池 +29.7%;扣 0.30% 往返成本后 -22.9%。**
- v2(收紧趋势、防追高)与 v1 差别很小:命中率 50%,累计成本前 +10.5%,扣成本后 -24.6%。三因子(5 日反转+低波动+非流动性)基线 Top5 更差:成本前 -51.9%。
- 一句话:**模型排序有一点点统计信息,但按规则挑 5 只股票,历史上没有稳定跑赢“随便买一篮子”,扣掉成本后是亏的。**

## 4. v2 每条新约束在历史上有没有用(5 日,v1 通过的股票中 被排除 vs 保留)

| 期间 | 约束 | 被排除 n / 跑输比例 / 平均相对 | 保留 n / 跑输比例 / 平均相对 |
|---|---|---|---|
| 探索期 2025-01~2026-09(非盲测) | T1 下跌(r20<-15%且MA20下行) | 215 / 35% / +1.69% | 1206 / 42% / -0.43% |
| 探索期 2025-01~2026-09(非盲测) | T2 20日涨幅>20% | 4 / 50% / -1.23% | 1417 / 41% / -0.11% |
| 探索期 2025-01~2026-09(非盲测) | T3 5日内涨停>=2 | 0(从未触发) | 1421 / 41% / -0.11% |
| 设计期 2022-07~2024-12 | T1 下跌(r20<-15%且MA20下行) | 3 / 100% / -5.82% | 348 / 39% / -0.20% |
| 设计期 2022-07~2024-12 | T2 20日涨幅>20% | 27 / 41% / +0.38% | 324 / 39% / -0.30% |
| 设计期 2022-07~2024-12 | T3 5日内涨停>=2 | 0(从未触发) | 351 / 39% / -0.25% |
| 全期 | T1 下跌(r20<-15%且MA20下行) | 218 / 36% / +1.59% | 1554 / 41% / -0.38% |
| 全期 | T2 20日涨幅>20% | 31 / 42% / +0.17% | 1741 / 40% / -0.14% |
| 全期 | T3 5日内涨停>=2 | 0(从未触发) | 1772 / 40% / -0.14% |

**解读**:T1(下跌趋势排除)在设计期只触发 3 次(都跑输),样本太少无法证明有用;在 2025–2026 探索期触发 215 次,被排除的股票反而**平均多赚 1.7%**、跑输比例更低——也就是说历史上“模型看好的下跌股”短期反弹更多。T2(20 日涨幅>20%)触发少、差别小;T3(5 日内≥2 次涨停)在 v1 已有的过滤下从未触发。**按事先约定,规则不因检验结果改动**;v2 的价值主要是风险控制(避免在趋势向下时抄底、避免追高),不是提高收益,而且历史上它可能**少赚**反弹。

## 6. 限制

- 2025–2026 不是盲测;2022-07 之后整体都已在 P1/P2 中被查看过。
- 历史回放没有 ST 过滤(历史名称不可得),现行规则会更严。
- 成本只用了简化的往返 0.30%/0.60%;P2 的显式成本(含价差、冲击)下,Top50 净年化已为负。
- 每周一期、5 日持有,周与周之间不重叠;20 日表现有重叠,只作参考。
